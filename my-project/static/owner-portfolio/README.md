# HOANG Portfolio V2

より視覚的に魅力のあるバージョンです。
日本のIT企業向けポートフォリオとして使いやすいように、内容は応募書類と整合する形で整理しています。

## ファイル構成
- index.html
- assets/css/style.css
- assets/js/main.js
- projects/barcode-pos.html
- projects/application-management.html
- projects/luna.html

## 使い方
1. ZIPファイルを解凍
2. `index.html` をブラウザで開く
3. 必要に応じて連絡先やGitHubを編集

## 追加で改善できること
- 実際の画面スクリーンショット追加
- GitHubリンク追加
- 英語版ページ追加
