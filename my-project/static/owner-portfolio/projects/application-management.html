Project Summary

応募情報を効率的に管理するため、応募登録、管理画面、抽選、CSV出力などの機能を持つWebアプリケーションを開発しました。

GitHub を見る → Demo を見る →

画面イメージ

目的

応募情報を効率的に管理するため、応募登録、管理画面、抽選、CSV出力などの機能を持つWebアプリケーションを開発しました。

主な機能・学習内容

  • 応募者情報の登録
  • 応募データの一覧表示
  • 管理画面
  • 抽選機能
  • CSV出力

工夫した点

  • データの登録から出力までの流れを整理し、管理者が必要な情報を確認しやすい構成を意識しました。
  • 画面とデータベースの関係を考えながら、処理の流れを分かりやすくしました。
  • 実装後も画面構成や処理の流れを見直し、改善を重ねました。

学んだこと

Webアプリケーションでは、画面だけでなく、データベース設計や処理の流れを理解することが重要だと学びました。

今後の改善

入力チェック、ログイン機能、権限管理などを追加し、より実務に近い管理システムに改善したいです。

面接で説明する時のポイント： 目的 → 使用技術 → 苦労した点 → 工夫した点 → 今後改善したい点、の順で話すと伝わりやすくなります。
