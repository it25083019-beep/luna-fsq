LUNA / Future Skill Quest

学習や生活の計画が続きにくい課題に対して、AIコンパニオン「LUNA」とRPG形式の成長体験で、目標を一緒に整理できるWebアプリを開発しました。

Project Summary

Python / FastAPI でバックエンドを実装し、チャット、生活記録、キャリア探索を一つのアプリにまとめました。Render上で公開しています。

Python FastAPI PostgreSQL Gemini JavaScript Render
GitHub を見る → Demo を見る →

画面イメージ

目的

勉強や生活の中で「今日何をすればよいか分からない」「計画が続かない」という課題を、会話できるAIコンパニオンと、RPG形式の成長体験で支えるアプリを作りたいと考えました。学校で学んだWeb開発に加え、API設計、データベース、クラウド公開まで一気通貫で実装することを意識しています。

主な機能・学習内容

  • ログイン・会員登録、管理画面
  • LUNAとのチャット（Gemini API連携）
  • 健康・お金・スケジュールなどの生活モジュール
  • Future Skill Quest：職業クラスタ提案、クエスト、EXP / レベル
  • PostgreSQLへのデータ保存と Render へのデプロイ
  • 同じAPIを使う Flutter アプリの着手

工夫した点

  • 会話だけで終わらせず、チャット内容から生活メモや予定を残せるようにしました。
  • 興味や性格の自由記述を、あらかじめ整理したキャリアクラスタへ対応づけ、RPGのクラスやクエストにつなげました。
  • エラーやAPI制限が起きても原因を切り分けられるよう、ログ確認と再試行を意識して実装しました。
  • ローカル開発とクラウド公開の違い（環境変数、データベース接続）を整理しながらデプロイしました。

学んだこと

画面を作るだけでなく、認証、API、データベース、外部AIサービスの連携、公開環境まで含めて考える必要があると学びました。特に、利用者が続きやすい体験にするために、機能を増やす前に「会話 → 記録 → 次の行動」の流れを整えることの大切さを実感しました。

今後の改善

Flutterアプリの完成、通知機能、パスワード再設定メール、キャラクター表現（Live2D / 3D）の追加など、実際に毎日使ってもらえる体験へ近づけたいと考えています。
